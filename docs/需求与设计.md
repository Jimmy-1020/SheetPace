# SheetPace 需求与实现设计

## 范围与要求

Windows 桌面版 Excel COM 加载项，目标 Office 2016–2024 / Microsoft 365，32/64 位，实际验证版本单独记录。

1. 原生筛选列表的各值旁显示出现次数。统计当前筛选区域的该列全部数据，排除标题，包含隐藏行，空白单独计数。
2. “鼠标光影”配专用网格与指针图标，支持两种模式：默认“点击选中”，依据当前选中的单元格、连续框选范围或多个不连续选区显示十字行列光影，移动鼠标不改变位置；“鼠标跟随”以鼠标所在单元格为交点，无需点击。光影不改变格式、内容、选区；仅绘制所选行列在当前窗口中的可见部分。
3. 原“颜色与透明度”入口重命名为“光影设置”，配网格与齿轮图标，可选择模式、调整颜色和透明度。功能可关闭，设置按用户保存；旧配置缺少模式键时采用点击选中。
4. 单个 EXE 用户级安装、升级、卸载，无需管理员权限。安装和卸载前关闭 Excel。

## 新增需求：连续与不连续选区光影（2026-10-07）

点击选中模式下，框选一横排或一列单元格时，光影应覆盖整个选区对应的全部行和列，十字交叉区域包含所有选中的单元格。改变框选范围后，光影随新选区更新。

使用 Ctrl 选择多个不连续单元格或区域时，各选区的行列光影同时显示，覆盖每一个选中的单元格。分别汇总各选区涉及的行和列，不把间隔中的未选行列整体加入高亮范围；增加或取消某个选区后同步更新。

- 横向框选 `B3:F3`：光影指示第 3 行及 B～F 列。
- 纵向框选 `B3:B8`：光影指示第 3～8 行及 B 列。
- 不连续选择 `B3`、`D5`、`F7`：同时指示第 3、5、7 行及 B、D、F 列。
- 不连续选择 `B3:D3` 与 `F5:F8`：同时指示第 3、5～8 行及 B～D、F 列。

本项已在 1.0.4 实现。单格、横向、纵向、矩形和 Ctrl 不连续选区均支持；光影使用行列区域并集，交叉处不叠加透明度。

## 实现边界

Excel 没有原生筛选选项的公开自定义渲染接口。使用 UI Automation 读取可见项，在行末以鼠标穿透的透明窗口绘制计数。受 Office 版本、可访问性树和日期分组影响；无法识别时不绘制。功能区另提供可靠的“计数筛选”面板，支持搜索、多选和按原始值筛选。

计数区域优先使用已有 AutoFilter / 表格，否则使用 CurrentRegion。读取 Value2 到内存，不写入工作簿。统一显示格式按显示值分组；混合格式以原始值显示，并说明边界。数字和日期筛选条件采用 Excel 的显示值。

## 架构

.NET Framework 4.8 AnyCPU 类库，手工声明 COM 接口，无 VSTO、PIA、NuGet 依赖。Excel 进程中的 `Connect` 负责加载项生命周期、Ribbon 桥接和轻量坐标采样；`IDTExtensibility2` 与 `IRibbonExtensibility` 按双接口 ABI 声明，生命周期参数使用引用 SAFEARRAY。

`SheetPace.VisualHost.exe` 是独立 STA 界面进程，通过指定 Excel HWND 的 `EXCEL7` 可访问性对象连接现有实例，运行光影、计数筛选、设置及定时器。计数及对话框的 Excel COM 访问在界面进程的 STA 线程完成。指针与活动单元格采样在 Excel 自身 STA 上用纯 Win32 消息窗口和 33ms 定时器完成，通过共享内存传输一致快照，避免每个格子的边界查询跨进程往返。点击选中模式读取 Selection.Areas，合并每个选区的行、列索引区间，分别保留间隔。逻辑范围按工作簿窗口、工作表、选区地址和活动合并区缓存，鼠标移动不重读 Areas。仅用可视轴命中和二分边界投影行列带，不逐格扫描整片选区；滚动、缩放、布局或选区变化时重新投影，另每秒刷新物理布局以反映行高、列宽和隐藏变化。设置刷新和 Ribbon 更新也在该 STA 定时器上执行。它不创建其他 Excel，也不关闭用户的 Excel。

`SheetPace.NativeMenu.exe` 独立运行 UI Automation；二进制标准输入输出协议传输可见菜单项目及物理屏幕边界。装饰窗口使用不激活、鼠标穿透的分层窗口绘制光影和计数。单组行列光影由三个互不重叠的窄条组成；多个行列带以原生窗口区域并集绘制，再统一设置窗口透明度，因此交叉处不会变深。两种路径均不创建整片工作区位图。共享内存传输可变长度行列带和几何修订号，读取端校验协议、数量上限及一致序列；只有形状或外观改变时更新覆盖窗。共享快照分别保存指针所在格与光影目标格，计数始终使用指针元数据，不受光影模式影响。只有实际筛选标题位置预热计数，普通单元格移动不读取筛选区域。菜单出现时优先使用鼠标所在且与菜单位置对应的筛选标题列，避免未改变的活动单元格指向另一列。

关闭加载项时先停止并销毁坐标采样定时器与消息窗口，再通知界面进程结束，并限时等待其释放 COM 代理；菜单进程在输入管道关闭后退出。超时仅处理插件自己创建的辅助进程。界面进程同时监测所属 Excel PID。

单个 WinForms 安装 EXE 内嵌三个运行文件，使用 HKCU 双注册视图注册加载项，提供卸载。升级恢复禁用记录时仅匹配完整 DLL 路径和 ProgID，先备份后恢复。用户设置与日志保留在 `%LOCALAPPDATA%/SheetPace`。测试只操作自建 Excel 实例及工作簿副本。

Ribbon 图标由代码绘制，通过 OLE `IPictureDisp` 回调交给 Office；Excel 进程中不使用 AxHost 或创建 WinForms 窗口。图标 COM 引用在加载项停用时释放。
