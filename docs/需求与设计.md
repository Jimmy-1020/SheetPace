# SheetPace 需求与实现设计

## 范围与要求

Windows 桌面版 Excel COM 加载项，目标 Office 2016–2024 / Microsoft 365，32/64 位，实际验证版本单独记录。

1. 原生筛选列表的各值旁显示出现次数。统计当前筛选区域的该列全部数据，排除标题，包含隐藏行，空白单独计数。
2. 鼠标悬停单元格时，以该格为交点显示半透明行列光影；不改变格式、内容、选区。
3. 光影颜色、透明度可调整；功能可关闭，设置按用户保存。
4. 单个 EXE 用户级安装、升级、卸载，无需管理员权限。安装和卸载前关闭 Excel。

## 实现边界

Excel 没有原生筛选选项的公开自定义渲染接口。使用 UI Automation 读取可见项，在行末以鼠标穿透的透明窗口绘制计数。受 Office 版本、可访问性树和日期分组影响；无法识别时不绘制。功能区另提供可靠的“计数筛选”面板，支持搜索、多选和按原始值筛选。

计数区域优先使用已有 AutoFilter / 表格，否则使用 CurrentRegion。读取 Value2 到内存，不写入工作簿。统一显示格式按显示值分组；混合格式以原始值显示，并说明边界。数字和日期筛选条件采用 Excel 的显示值。

## 架构

.NET Framework 4.8 AnyCPU 类库，手工声明 COM 接口，无 VSTO、PIA、NuGet 依赖。Excel 进程中的 `Connect` 仅负责加载项生命周期和 Ribbon 桥接；`IDTExtensibility2` 与 `IRibbonExtensibility` 按双接口 ABI 声明，生命周期参数使用引用 SAFEARRAY。

`SheetPace.VisualHost.exe` 是独立 STA 界面进程，通过指定 Excel HWND 的 `EXCEL7` 可访问性对象连接现有实例，运行光影、计数筛选、设置及定时器。Excel COM 访问在界面进程的 STA 线程完成。它不创建其他 Excel，也不关闭用户的 Excel。

`SheetPace.NativeMenu.exe` 独立运行 UI Automation；二进制标准输入输出协议传输可见菜单项目及物理屏幕边界。装饰窗口使用不激活、鼠标穿透的分层窗口绘制光影和计数。菜单出现时优先使用鼠标所在且与菜单位置对应的筛选标题列，避免未改变的活动单元格指向另一列。

关闭加载项时先通知界面进程结束，并限时等待其释放 COM 代理；菜单进程在输入管道关闭后退出。超时仅处理插件自己创建的辅助进程。界面进程同时监测所属 Excel PID。

单个 WinForms 安装 EXE 内嵌三个运行文件，使用 HKCU 双注册视图注册加载项，提供卸载。升级恢复禁用记录时仅匹配完整 DLL 路径和 ProgID，先备份后恢复。用户设置与日志保留在 `%LOCALAPPDATA%/SheetPace`。测试只操作自建 Excel 实例及工作簿副本。
