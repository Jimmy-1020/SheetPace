# 1.0.0 测试记录

验证日期：2026-10-05。环境：Windows，Microsoft 365 Excel 16.0.20430.20118，64 位，.NET Framework 4.8。

| 项目 | 结果 | 覆盖 |
|---|---|---|
| 基础自动测试 | 20 项通过 | 文本重复、大小写、空白、单格、COM 数组、通配符、错误值、日期分组、透明度、设置保存、十万行计数 |
| Excel 集成测试 | 16 项通过 | 实际 Excel 计数与筛选、保留其他列条件、数字显示格式、日期、空白、多个 ListObject、同名工作表的工作簿身份检查、加载项连接与释放 |
| 用户指定工作簿 | 50 项通过 | 五张工作表的各等级频数与实际可见行数一致；测试仅操作副本；原文件 SHA256 未改变 |
| 合成数据界面测试 | 通过 | 悬停光影显示；原生筛选 UIA 识别；各项数量标签显示；空白数量 |
| 用户工作簿界面测试 | 通过 | 只读打开测试副本，在“1班”验证悬停光影及 F5 成绩列原生筛选标签 |
| 安装包自检 | 通过 | 内嵌 DLL 的 SHA256、COM 类存在、注册计划、卸载路径覆盖；不写注册表 |
| 真正安装后的 COM 启动与卸载 | 尚未验证 | 本次默认执行环境拒绝注册表写入；界面测试使用直接连接的插件实例 |

## 验证边界

未实测 32 位 Office、其他 Office 版本、多显示器混合 DPI、全部复杂数字格式、全部日期层级、超大型工作簿以及所有拆分/冻结布局。AnyCPU 和双注册视图已经实现，不能据此声称已完成这些平台的实际回归。

原生计数界面使用 UI Automation 和无激活浮层；不支持的菜单不会被改写，功能区计数窗口仍可使用。光影使用鼠标命中测试确定单元格边界，并缓存同一单元格的几何信息。
